## 统计与版本说明

- 年报是财报子类，以上五类互斥统计。财报合计 657 份，招股说明书 16 份。
- 包含 22 份正式报告摘要和 1 份公司发布英文摘要译本；去掉摘要类为 650 份。清单保留相应版本标记。
- 保留 1 份已取消的历史季报及其更新版本，以保留实际持有文件情况；不应以已取消版本作为当前披露依据。
- 招股说明书包括 11 份正式披露稿、3 份注册稿、2 份申报稿。
- 仅对完整文件字节去重，未将同公司同期间不同格式、修订稿、报告摘要、独立审计财报或内容部分重叠的合集强行合并。
- 报告期间主要覆盖 2016—2026 年。NVIDIA 2027 财年第二季度公告的实际报告截止日为 2026-07-26，保留原报告财年口径。四份招股稿的签署日期尚未核实，清单明确标注。
- PDF 根据标题页、前几页及必要扫描页核验分类；HTML 核验主文、财务章节及尾部。源文件字节保持不变。
- 不收录研究总结、索引网页、链接文件、投资者活动记录、非目标公告、模板和 PDF 派生 TXT。此库不是全盘资料完备性声明。

## 浏览和校验

文件按 `reports/<类别>/<报告年份>/` 分类，文件名包含公司、期间、必要版本标记和哈希前缀。清单使用仓库相对路径，不含原设备绝对路径。

所有报告均为普通 Git 文件，无 Git LFS 指针。克隆后可在仓库根目录运行：

```bash
shasum -a 256 -c SHA256SUMS
```

原披露文件中的公司、审计及签署信息保留于原文。
